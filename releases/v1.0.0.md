# Conlab v1.0.0 MVP

Conlab v1.0.0 is the first usable MVP of the controlled collaboration text ledger.

This release is intended for internal evaluation and early project usage. It supports local browser usage and a Tauri desktop packaging path for macOS `.dmg` builds.

## What Is Included

- Git-backed workspace storage through `conlab.json`
- GitHub repository support
- GitLab repository support, including internally hosted GitLab instances
- Repository role mapping into Conlab roles:
  - read-only
  - contributor
  - reviewer
  - admin
- Bucket creation with name, description, review mode, and active/archived status
- Review-required buckets where proposed content must be accepted or rejected
- Auto-accept buckets for low-risk content collection
- Content event log with create, revise, and delete actions
- Delete-of-delete behavior to restore previously deleted rendered content
- Questions and decisions as controlled discussion events
- Markdown rendering for bucket descriptions, content, comments, questions, and decisions
- Rendered bucket text generated from accepted event log entries
- Rendered history navigation with `<<` and `>>`
- Markdown export of the currently visible rendered bucket state
- In-app notification banner when the connected Git workspace changes remotely
- Collapsed-by-default rendered text and event log panels to keep the edit form prominent
- Playwright UI test coverage for the Git-backed workspace flow

## Desktop Packaging

This release includes a Tauri desktop app scaffold.

After installing Rust/Cargo, build the macOS bundle with:

```bash
make desktop-build
```

Generated artifacts are written under:

```text
src-tauri/target/release/bundle/
```

Ad-hoc signed `.dmg` builds can be uploaded directly to GitHub Releases for MVP distribution. macOS may show a Gatekeeper warning on first launch because the app is not Apple-notarized.

## Install

For local browser usage:

```bash
make run
```

For desktop bundle creation:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
make desktop-build
```

## Known Limitations

- No automatic app updater yet. New versions are installed by downloading the next `.dmg` and replacing the old app.
- Desktop builds are ad-hoc signed but not Apple-notarized.
- Tokens are stored locally in browser/app local storage for the MVP.
- GitHub/GitLab email notifications are not triggered by Conlab; the app uses in-app polling notifications.
- No advanced admin workflow beyond repository role mapping and bucket settings.
- No multi-file bucket export yet; export is per visible rendered bucket state.
